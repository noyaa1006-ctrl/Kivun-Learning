# Kivun Learning
כיוון (Kivun Learning) היא פלטפורמה חכמה שמחברת תלמידים והורים למורים פרטיים שמתאימים באמת לצורך שלהם. התלמיד מגדיר מקצוע, רמה, מטרה, תקציב, זמינות וסגנון למידה — ומקבל מורים מתאימים עם הסבר ברור למה הם מתאימים. אפשר לראות פרופילים, ניסיון, מחיר, דירוגים מאומתים וזמינות, לשוחח עם המורה, לקבוע שיעור ולשלם במקום אחד. מורים בונים פרופיל מקצועי עם ניסיון, תארים, מקצועות, מחיר ושיטת הוראה, מנהלים את הפרטים שלהם ומקבלים תלמידים מתאימים. אחרי כל שיעור, “דרכון התקדמות” מתעד את המטרה, מה הושג ומה הצעד הבא — כדי שהלמידה לא תהיה רק שיעור חד־פעמי, אלא תהליך שמתקדם.
